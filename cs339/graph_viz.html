What does Order change?

This sets the order in which DFS pushes neighboring vertices onto the stack, based on their left-to-right positions in the graph.

Right → Left: push rightmost first, leftmost last. The leftmost eligible vertex is then on top and explored next. Left → Right reverses this.

The last vertex pushed is the first one popped. Changing the order can change the exploration sequence, the path found, and the number of steps before reaching the target.

The reachability result stays the same: if a path to the target exists, DFS finds one with either order. DFS does not guarantee the shortest path.
