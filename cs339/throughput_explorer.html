How to read this model

The bottleneck limits throughput. Waiting before it adds delay. A full buffer causes arriving data to be dropped. Increase the outgoing capacity above arrivals to drain a queue.

Queues count fixed-size teaching packets, each containing 1 Mbit (125,000 bytes). This deliberately enlarged packet size keeps the counts easy to follow; it is not a typical Internet packet size. Throughput is calculated from completed packet deliveries.

Each router has one combined queue display, with colors showing each connection. Router 1 divides 20 packet slots equally: 10 each for two connections, 6 each for three (18 total), or 5 each for four. Router 2 combines 20 slots per server. Single Connection has 20 slots.

This fixed-step teaching model omits propagation delay, TCP adaptation, retransmission, protocol overhead, and random traffic. Fixed senders do not slow down, so persistent overload causes packet loss. Animated markers illustrate batches of data, not individual packet timing.

Link labels show capacity; receiver measurements show actual throughput. After a capacity change, buffered data may temporarily raise throughput above the steady-state prediction.
