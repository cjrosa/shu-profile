            How is the next word chosen?

            The model gives each possible next word a probability. You decide how to choose:

            Manual: Select Predict, then choose a word yourself.

            Sampling: Auto Generate chooses randomly using the probabilities. After “New Haven,” pizza has a 50% chance; sets and is each have 25%. Pizza is most likely, but not guaranteed.

            Greedy: Auto Generate always chooses the highest-probability word—here, pizza. The same starting words produce the same passage. Ties use the word that appears first in the training text.

            A different word changes the context for the next choice, so sampling can produce different passages. Neither method guarantees a meaningful sentence.

            Use the Auto Generate dropdown to choose a mode. Switching modes starts a fresh passage.

            Discovery: By repeatedly predicting the next word, a simple language model can generate text. But the result depends on the patterns it has observed, not an understanding of what the words mean.

            Context capacity and memory

            Different models support different context capacities, measured in tokens rather than words. Token counts depend on the tokenizer. Longer text uses more capacity.

            A context window is not long-term memory or a measure of understanding or reasoning. Larger capacity does not guarantee reliable use of distant information.

            Without the earlier information in its current input, a model might still produce a plausible continuation from its learned parameters. This explorer does not predict what any particular model would generate.

            Discovery: A language model can only directly use the tokens available within its current context. When relevant information falls outside that window, the model cannot directly refer to it through the current input.

            Projection rules and teaching parameters

            For a representation [a, b, c], Query = [b + 0.5c, a − 0.5c]; Key = [a + 0.25c, b − 0.5c]. Score(i, j) = (Qᵢ · Kⱼ) / √2. The same projections apply at every position.

            Fixed representation lookup (case and punctuation ignored): the/and/at/a/after = [−0.5, 0, 0.2]; team/dog/ball/conference/flight/train = [1, 0, 0.2]; pizzas/Marie = [2, 0, 0.2]; they/She = [0.2, 1.5, 0]; got/arrived/chased/was/were = [0, 0.2, 1]; cold/exhausted/long/delayed = [0.5, 0.5, −0.5]. Coordinates are invented teaching numbers, not semantic measurements.

            Technical assumptions and limitations

            Causal masking excludes future positions before stable softmax normalizes the permitted scores. Calculations use full precision; displayed values are rounded. Vector colors match the NLP & RNN Visualizer: blue for positive values, purple for negative, gray for magnitudes below 0.0005; intensity uses one fixed range covering every Query and Key value in the teaching vocabulary (maximum magnitude 2.05), so different magnitudes remain distinct. The sign hues, saturation, and lightness endpoints match the Visualizer. Dimensions are unnamed numerical coordinates, not named semantic features.

            In trained transformers, learned projections produce Query, Key, and Value vectors from each token representation. These teaching parameters are fixed, not learned. This is one head; real transformers generally use multiple heads and layers. One word per position is a simplification; tokenizer boundaries may differ. Weights are numerical compatibility, not probabilities of a pronoun’s referent or proof of understanding. Query and Key descriptions are analogies, not literal semantic questions.

            From initial embeddings to context

            Initial token embedding: Within a given model, the same token ID retrieves the same learned starting representation.

            Contextual representation: A model transforms that starting representation using surrounding tokens, so it can differ across contexts.

            Identical written words need not have identical token sequences. Having information inside a context window does not guarantee that a model uses it correctly.

            Discovery: Words do not carry meaning in isolation. Their interpretation depends on surrounding language, word order, and relationships with other words.
