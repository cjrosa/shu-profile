# Chapter 4, Scene 1: inspection-only attention

Section 9 of the supplied milestone is replaced by the user's Interaction Scope — No Weight Editing. Students select targets and inspect sources. No sliders, editable weights, normalization inputs, context-limit controls, or student-defined distributions are exposed. Weight editing requires explicit approval in a later milestone. Q/K/V calculations belong in Scene 2.

The scene uses one authored teaching head and word positions, not real tokenizer boundaries or trained-model output. All positions through the selected target, including itself, are eligible. Future positions have zero weight and no connection.

`llm-self-attention.js` separates the pure `distribution` function from rendering. Example-specific fixed integer rows are documented next to their sentences. Other target rows use the deterministic positive integer score `1 + ((source+1)*(target+seed+1)+source*source) % 9`, with zero-based positions and per-example seeds 1, 3, 5, and 7. These are arbitrary teaching parameters, not a semantic model or Q/K/V calculation. Scores are normalized over permitted positions only. Floating-point totals equal one within numerical precision. Numbers are rounded to one decimal; connector widths use unrounded weights. Stroke width is `1.25 + 8*weight`; highlighted connections change color, not weight.

The longer example uses the whole available prefix. The earlier request for an adjustable context limit is superseded by the prohibition on additional calculation controls. Reset restores the current example's starting target and clears source highlighting. Example switching resets both. Rendering is synchronous and introduces no animations, timers, network calls, or inference.

Visual reuse: Chapter 2 panel, message, and tokenizer picker classes; Chapter 3's six-column positions, token rectangles, SVG title classes, semantic colors, and arrow-key target selection. Connections are undirected, as in the preceding attention visualization. Curves use staggered depths and target attachment points, with separate cross-row lanes and a right-side self loop to reduce overlap. Inspecting a source fades the other connections without changing their weights. Hover or percentage selection inside a word cell highlights an individual contribution. Shift-click/Shift+Enter also inspects a permitted source.

Validation: all 44 tests in `llm-self-attention.test.cjs`, `llm-explorer.test.cjs`, and `llm-transformer-ui.test.cjs` pass. The broader Explorer run identified six existing failures in `llm-rnn-ui.test.cjs`; all six reproduced using the unchanged HEAD HTML and navigation source. Tests cover every target in all four examples, causal masking, normalization, synchronized cell percentages/connections, source hover and selection, keyboard navigation, example changes, reset, and rapid changes. Browser visual comparison, computed typography, responsive layouts, and projector readability remain unverified: the session's browser inventory was empty.

Percentages appear inside the word cells beneath each word; future cells show Unavailable. The separate weight bars have been removed. Clicking a word selects a target; clicking or keyboard-activating its percentage inspects that source without changing the target.
