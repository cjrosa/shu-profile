About this workspace
Real Python runs locally in your browser. Edit or add Python files while stopped. Start always runs main.py. Stop terminates the runtime; Restart creates a fresh one.
Current Chrome or Edge is recommended. The first load downloads Python from jsDelivr. Desktop GUI, operating-system access, and arbitrary native packages are outside this tool’s scope.
Watch expressions and breakpoint conditions are Python expressions. Prefer expressions that only read values: function calls can change program state. Code and watches stay in this tab; download or copy work before closing it.
