Learning to debug Python

A debugger lets you pause a running program and examine what it is doing. Debugger Explorer runs actual Python in your browser, with an editable workspace and a guided two-file investigation.

Your first investigation

  1. Predict the output of the temperature converter: 32.0, 68.0, and 212.0.
  2. Select Start. The yellow line is the next line to execute, not a line that has already completed.
  3. Click beside line 6 in main.py to set a breakpoint. Add index and len(temperatures) to Watch.
  4. Continue to the breakpoint. Step Over the assignment, then Step Into the conversion call on line 7.
  5. Compare the function's locals with its caller by selecting call-stack frames. Step Out to finish the function.
  6. Set your breakpoint condition to index == 1, restart, and continue. Observe the second iteration.
  7. Continue to see the missing result. Stop and repair the loop bound. Check repair compares the program's output with the expected three values.

Execution controls

ControlWhat it does
Start / Continue · F5Starts main.py and pauses at its first executable line, or resumes to a breakpoint or completion.
PauseRequests a pause at a Python trace checkpoint. Long native-library operations may delay it; Stop remains available.
Step Over · F10Executes the next line, including its function calls. Breakpoints inside those calls still apply.
Step Into · F11Enters a Python function in your workspace. Library internals are skipped.
Step Out · Shift+F11Finishes the current function and pauses in its caller, unless a breakpoint is reached first.
RestartCreates a fresh runtime with your current files, watches, and breakpoints.
StopTerminates the worker and unlocks the editor, including when a program loops forever.

Browser or operating-system shortcuts can intercept function keys. The toolbar always provides the same actions.

Variables, watches, and stack frames

Locals are automatically collected from the selected function call. At the top level, they are the module's variables. Values that changed since the preceding inspection flash blue. Representations are limited to 500 characters.

Watch evaluates expressions you choose in the selected stack frame. A name unavailable in that scope displays an error; that does not stop the program. Use expressions that read values, because calls in expressions can change program state.

The call stack lists active workspace calls, current call first. Selecting a caller changes the variables and source location being inspected; it does not move execution backward. Step controls operate on the actual current call.

Breakpoints

Click the line gutter to add or remove a breakpoint. Use its checkbox to disable it without deleting it. Enter a Python expression for a conditional breakpoint, or leave the condition empty for an ordinary breakpoint. Invalid conditions pause with an explanation. Set breakpoints on executable lines: comments and blank lines do not execute. Line numbers stay fixed when you edit code, so review them after inserting or deleting lines.

Write your own Python

Stop the program before editing. Select file tabs or use Explorer to switch files. The + beside Explorer adds a Python file. Use simple module names such as helpers.py, then import them from main.py. Start always executes main.py. Input prompts appear in the terminal; enter a value and select Send.

Functions, recursion, classes, collections, and standard Python expressions execute in the real interpreter. This first version focuses on single-threaded, synchronous teaching programs. Async tasks, threads, desktop GUIs, unrestricted operating-system access, and arbitrary native packages are outside its supported debugging scope. Python exceptions appear in the terminal with their traceback; edit and restart to investigate.

Loading, compatibility, and reset

The runtime is Pyodide 314.0.8, downloaded from jsDelivr. Initial loading requires internet access. Interactive debugging requires WebAssembly JavaScript Promise Integration; use current Chrome or Edge. If it is unavailable, the tool shows a compatibility message rather than simulated execution.

Code runs in a separate browser worker, without a Python application server. This is an educational workspace for your own code, not a security sandbox for untrusted scripts. Files and edits remain in this tab only. Copy work before closing or reloading. Reset stops execution, restores the starting files, clears watches, breakpoints and output, and restores the debugger panels, toolbar position, and lesson progress after confirmation. It preserves your theme preference.

Arrange the workspace

The icon rail switches between Explorer and Run And Debug. When stopped, Run And Debug shows a launch button; during a session it shows Variables, Watch, Call Stack, and Breakpoints. Use the + in the Watch heading to enter an expression. The other heading controls remove all watches or collapse their values.

Drag the six-dot handle to move the floating debugger toolbar within the editor workspace. With the handle focused, arrow keys move it and Home restores its starting position; double-clicking the handle also restores it. Each icon has a tooltip and an accessible name.

The theme button switches the rounded IDE card between light and dark and remembers your choice in this browser. The surrounding page and guided lesson stay light. In light mode, the editor and terminal are white and the sidebar is light grey. Python syntax colors update while typing. The editor and terminal use Consolas.

Quick files and commands

Press Ctrl+P to search the Python files in this workspace. Press Ctrl+Shift+P for existing tool commands, or type > in the file picker. Use Up/Down and Enter to choose an item; Escape closes the picker and returns focus.

Commands include theme and view changes, debugging controls, watches, breakpoint configuration, lesson navigation, terminal clearing, and workspace reset. Only currently available actions are shown. Breakpoint commands use the editor cursor line; edit a condition after creating a breakpoint there. Reset retains its confirmation dialog. On macOS, Command can replace Ctrl.
